# studieplanlegger

Brukeren kan planlegge bruk av tid tidligere, nå og videre. I planleggeren kan brukeren sette opp mål og planlegge hvor mye tid som trenges for å nå målet. Videre kan brukeren visualisere tidligere arbeid ved å se på mengde tid eller progresjon som ble gjort tidligere over lenger perioder. 

Jeg håper studieplanleggeren kan komme til godt nytte til de som sliter med å balansere tid og arbeid til studiet :)
